# Map data

`countries.json` and `cities.json` are derived from [Natural Earth](https://www.naturalearthdata.com/)
(1:50m Admin 0 countries, 1:110m populated places), which is in the public domain.
Rings were simplified and rounded to 0.01°. Regenerate from the GeoJSON in
github.com/nvkelso/natural-earth-vector if more detail is needed.
